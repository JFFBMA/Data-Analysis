Resumen Ejecutivo de Ventas Walmart

Analista de datos en Walmart.

la Dirección Comercial necesita un resumen ejecutivo para decidir determinados ajustes de presupuesto e inventario.

El objetivo de Walmart es limpiar, organizar y analizar los datos de ventas semanales de 2012, con el fin de responder a preguntas clave de negocio mediante KPIs bien definidos y visualizaciones claras..

Para ello, usarás tres fuentes reales de datos incluídas en el Excel:

Datasets
Tabla transaccional
•	`raw_ventas` → columnas: tienda, dept, fecha, ventas_semanales, esferiado.
Tablas de lookup
•	`raw_departamento` → columnas: dept, nombre_dept.
•	`raw_tiendas` → columnas: tienda, tipo (A/B/C), tamaño.


Tu misión será limpiar, unir y analizar las tres bases para obtener información útil para la toma de decisiones.

## 🧠 Objetivo del Proyecto

1.	Preparar datos para el análisis (limpieza, enriquecimiento, documentación).
2.	Construir KPIs clave para evaluar la eficiencia y la participación.
3.	Crear dashboards dinámicos con filtros y visualizaciones útiles para los stakeholders.
4.	Comunicar hallazgos ejecutivos mediante el método C→F→I.
5.	Aplicar QA para asegurar la calidad y trazabilidad del análisis.
